System Requirements
===================

The Audience Display controls all audio and graphics intended for audience consumption. It can be run on the same machine as FMS or on a separate machine located on the same network as the FMS installation.

The machine being used as the Audience Display must meet these minimum requirements:

* Operating System: Windows 11
* Browser: Google Chrome
* Memory: 8 GB RAM
* Hard drive: 16 GB free hard disk space
* Graphics: Modern graphics card
* Resolution: 1920x1080 at 100% scaling (based on the Windows scaling settings)
* Network: Wired Ethernet connection to the FMS network (wireless is not supported)

For game sounds, the machine must have speakers or connect to a system capable of accepting the audio output of the machine (such as a 1/8" headphone jack or HDMI).
