Downloads
======================

.. image:: images/downloads.png

Several commonly downloaded programs are stored on the field server for quick access without requiring an internet connection (as not all events have internet access).
It is recommended to download files to the server and place them on a USB Stick, or download the to a machine that is connected via Ethernet to the field network.

* Radio Kiosk - exe installer to turn a target machine into a radio kiosk to program team radios for use on the playing field
* Robot Simulator - exe installer to turn a target machine into a robot simulator to verify field access point operation

The Audience Display and FTA Notepad are no longer downloads. Both run in a web browser from the field server website:
see :ref:`About Audience Display <audience-about-web-index>` and the FTA Notepad section of this manual.
