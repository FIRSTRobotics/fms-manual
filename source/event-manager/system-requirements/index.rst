System Requirements
===================

In order to install FMS, the target machine must meet these minimum requirements:

* Operating System: Windows 11 (64 bit)
* CPU: 2.0 GHz
* Memory: 8 GB RAM
* Hard drive: 16 GB free hard disk space
* Hardware: Ethernet and USB Port
* Resolution: 1920x1080 or higher
