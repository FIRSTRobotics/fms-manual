Multi-field Setup
======================

For events that have more than one playing field.

Setup
-----

.. image:: images/multi-field-setup-0.png
    :align: center
    :width: 450

|
| Multi-field setup is used for configuring FMS for use at events with more than one active playing field. Do not modify anything within this tab without FRC Engineering support.

This mode is not available to events without coordination with *FIRST* . It is used at the *FIRST* Championship.
See :ref:`Multi-field Events <scorekeeper-multi-field-events>` for how the fields work together and what each one can do.

* **Field Type** - Primary, Secondary or Practice. Changing it requires FRC Engineering authorization, and it cannot be
  changed in Off-Season FMS.
* **Master Field Name** - the address of the Primary field's server. It is blank on the Primary field.
* **Test Connection** - available on Secondary and Practice fields. Reports which multi-field event the Primary field
  has active, or that it does not have one active.
