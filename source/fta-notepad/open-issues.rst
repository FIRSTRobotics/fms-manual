Open Issues
===========


.. image:: images/fta-notepad-open-issues.png
    :align: center

| 
| The Open Issues page lists all open issues for each team.

Each issue shows the following information:

* Issue Type
* Match Name
* Checkbox
* All comments on the issue

Clicking the button at the top of the page will resolve all issues that have the checkbox clicked.
